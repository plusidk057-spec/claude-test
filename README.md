# claude-test

A Roblox project managed with [Rojo](https://rojo.space).

## Layout

| Folder       | Studio location                          |
| ------------ | ---------------------------------------- |
| `src/shared` | `ReplicatedStorage.Shared`               |
| `src/server` | `ServerScriptService.Server`             |
| `src/client` | `StarterPlayer.StarterPlayerScripts.Client` |

## Getting started (on your own computer)

1. Install Rojo: `aftman install` (or see https://rojo.space/docs/v7/getting-started/installation/)
2. Install the Rojo plugin in Roblox Studio.
3. Run `rojo serve` in this folder.
4. In Studio, open the Rojo plugin and click **Connect**.

To build a place file instead: `rojo build -o claude-test.rbxl`
